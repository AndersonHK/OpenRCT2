# Rendering manifests and reference methods

These manifests identify frozen inputs, required parity groups and explicit exceptions. Rendering tools read this location. Preserve oracle identity and hash-bound records; a moved receipt is not a renewed qualification. Historical paths inside JSON can be resolved through the [relocation map](../../development/document-relocations.json). Follow [artifact retention](../../development/vulkan-artifact-retention.md) to restore locally archived captures. The support inventory is a dated platform audit, not proof of current CI health.
