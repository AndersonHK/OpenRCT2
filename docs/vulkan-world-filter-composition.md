# Ordered native world filters (candidate, not yet executed)

The previous native world pass copied opaque indexed colour once and applied every deferred palette filter to that same immutable background. Two overlapping underground Darken1 surfaces therefore darkened once. This also lost the order of water palette masks, literal water overlays, scenery/station/entrance glass, Dodgems darkening and blended selected-vehicle art.

The replacement collects only deferred fragments that pass the final opaque depth test. Opaque coverage, foreground grids and UI already present in that depth buffer hide older filters. Collection does not write depth or colour. Each surviving fragment stores its full painter rank and either a palette-row operation or a literal indexed colour. A GPU resolve sorts each pixel's linked list in storage and folds the operations in increasing painter order. This uses the existing world command stream and device; it does not construct a CPU draw list or download pixels.

Storage is bounded to two8-byte nodes per display pixel, capped at0x00fffffe nodes and the device storage-buffer range. At3840x2160 this is126.5625MiB of nodes,31.640625MiB of heads and7.91015625MiB of packed output, plus20 control bytes. The former7.91MiB background image is removed. Node links reserve24 bits, operations8 bits, and painter order31 bits (preserving the renderer's complete22-bit interval). A pixel may have at most256 surviving filters. The sort uses scalar indices and storage-buffer links, with bounded non-unrolled loops; no per-pixel private node array is allocated.

Collection flags global pool exhaustion or an invalid palette/order. The first resolve dispatch validates and sorts all lists, reporting overlong lists or duplicate ranks. A second dispatch folds only when the shared world status is clean; any error writes zero for the entire canvas. The existing four-byte asynchronous completed-frame status reports the error after its submission fence. This rejects the frame as incorrect; it is **not** a guarantee that presentation cannot have queued the blank failed frame before the asynchronous failure is observed.

The initial implementation clears the full head buffer, dispatches two full-canvas compute passes and copies packed output back to the indexed canvas even with no deferred fragments. A global allocation atomic is performed per surviving fragment. These costs require actual4K timing. A later GPU-generated indirect resolve/writeback path could skip work on empty frames without CPU readback, but is not claimed here.

The device must explicitly support and enable core fragmentStoresAndAtomics, support25 storage-buffer descriptors in the combined pipeline layout and fit the canvas/head ranges and dispatch count. Canvas size is derived from the actual render target. All resources follow the existing serial queue and owner-fence lifetime; scratch is reused only after explicit dependencies on prior shader/transfer reads.

Qualification added in VulkanWorldObjectLayerTests.cpp uses the actual native world pipeline and immutable selected-vehicle parent/child packet: two Darken1 operations; opaque ink between filters; both noncommuting water/glass orders; both literal-water/glass orders; painter depth above2^21; accepted256-filter boundary; per-pixel overflow; global pool overflow; and removal after a filtered frame. The new cases have not been built or executed by the author. Existing terrain/water/glass, UI, auxiliary and original-art underground captures remain required before acceptance.
