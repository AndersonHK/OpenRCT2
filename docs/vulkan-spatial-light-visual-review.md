# Spatial GPU LightFX visual qualification

The resolved-command backend fixture passes run-21 on the captured NVIDIA RTX 5070 Ti driver: all 12 tests, 13 captured frames, and 26 indexed/physical comparisons are exact. The integrated run passed 134/134 tests with no validation messages. This qualifies the bounded synthetic spatial accumulation cases, not actual main-UI light discovery or world occlusion.

The frozen CPU `ResolveLightCommandForCanvas` and `RasterizeResolvedLightCommands` produce the reference intensity. A literal copy of frozen `MixLight` arithmetic expands those intensities and indexed colours; the result passes through an actual accelerated SDL ARGB8888 texture and default backbuffer. Vulkan receives the same resolved commands and baked falloffs, with **no CPU intensity map**. Its backend throws if GPU accumulation cannot consume a command-only snapshot. Successful enabled captures therefore prove the GPU route for these frames, including empty accumulator clearing. No renderer correction or exception was needed.

Coverage includes each of lantern0–3 and spot0–3 at an odd 321×279 extent, mixed intensities including 0/1/63/127/128/254/255, saturated overlap, clipping across edges and corners, the legacy small-canvas source stride at 79×61, an initially empty light set, and removing overlapping lights on the same backend. Raw indexed and physical reference/candidate bytes, PNG triplets, commands, shader/falloff/palette hashes and CPU intensity diagnostics are retained under `obj/vulkan-parity/run-21/samples/SpatialLight`.

Agent `decode_assets` manually opened all reference/candidate/diff physical triplets for Lantern3, Spot3, OverlapSaturation, EdgesCorners, SmallCanvasStride, OverlapSaturation_Cleared and Empty (21 PNGs). The large lantern shows the matching central falloff; the spot is visibly dimmer and matches its reference. Overlap has matching saturated central highlights and surrounding graded light. Edge light lobes stop at the same canvas boundaries. The small canvas retains the same partial falloff and colour blocks. Both cleared and initially empty frames show the same unlit colour pattern with no residual glow. Every viewed difference image is black. Exact image SHA-256 receipts are in [vulkan-spatial-light-run21-review.json](vulkan-spatial-light-run21-review.json).

Run-20 contained no spatial images: all 12 tests stopped before rendering because the required shader-directory environment variable was absent. The runner now explicitly supplies the same shader directory it hashes. That was an input setup failure, not a rendering divergence or accepted exception. The earlier build warning was an SDL enum/Uint32 comparison fixed solely in the test.

Remaining qualification: natural source discovery, map/entity projection, occlusion, per-paint adaptation and linger, palette transitions, actual UI lighting and resize behavior. These require matched paint ordinals in independent fresh-process UI runs. This fixture does not reconstruct or claim GPU intensity readback; physical captured RGBA is the authoritative GPU result, while the saved intensity image is explicitly CPU reference diagnostic data.
